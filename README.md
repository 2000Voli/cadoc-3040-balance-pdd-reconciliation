Python tool for reading CADOC 3040 XML files and consolidating balance, PDD and loss values for regulatory reconciliation.

---

# Overview

This project was developed to validate whether CADOC 3040 XML files generated by internal systems were complete before submission to the Brazilian Central Bank.

The tool processes XML files, consolidates balance, PDD and loss values, and exports an analytical Excel report to support pre-submission validation.

---

# Problem Solved

The team faced recurring questions regarding reported balances in CADOC 3040 files.

This automation helped verify XML completeness before regulatory submission, reducing operational risk and supporting the closing process.

The solution became part of the team’s operational workflow.

---

# Main Features

- Batch reading of CADOC 3040 XML files
- Incremental XML processing
- Balance consolidation
- PDD consolidation
- Loss consolidation
- ClassOp-level aggregation
- Encoding detection
- Excel report generation
- Support for large XML files
